# CE 402 Foundation Design Platform

Web-based calculation platform and site design for the CE 402 group assignment (isolated footings on a 30 m x 15 m grid, IS 6403:1981 bearing capacity, IS 1904:1986 settlement limits, alternative foundation).

## Use it
Open `index.html` in a browser (or `dist/standalone.html`, the same page in one file). No installation, no server, no sign-in; every calculation runs in the browser from the numbers typed into the forms.

| Tab | Module |
|---|---|
| 1 Soil profile | layered profile, measured + design water table, drawn profile, stress table |
| 2 Parameters | IS 2131 SPT corrections (every step shown), direct-shear least squares c'/phi', UU cu, oedometer Cc/Cr/sigma'c |
| 3 Bearing capacity | IS 6403:1981 strip/square/rectangular/circular, general/local shear, all factors displayed, net safe capacity |
| 4 Stress increase | Boussinesq centre/corner of a rectangle, superposition at any point, 2:1 method, plot against depth |
| 5 Settlement | Schmertmann (granular), NC/OC consolidation in sublayers <= 0.5 m, time-settlement with chosen drainage |

SI units throughout (kN, kPa, m, mm); the unit is shown next to every input and output. `src/examples.js` holds optional example boreholes loaded only when a "Load BH-x" button is pressed; no calculation reads it.

## Layout
```
index.html            the page (loads src/engine.js, src/examples.js, src/app.js)
src/engine.js         calculation engine, pure functions, no site data; every equation has a "SRC:" comment
src/app.js            forms, plots, tables (drawing only; calls the engine)
src/examples.js       OPTIONAL example data (generated by tools/make_examples.js)
data/site.json        the assignment's site data (used only by the design scripts, never by the page)
tools/site.js         isolated-footing design      node tools/site.js <g> <Df>
tools/raft.js         raft / compensated raft      node tools/raft.js <g> <Df> <t>
tools/derive.js       laboratory + SPT derivations node tools/derive.js
tools/sources.js      builds docs/sources.md from the SRC: comments
tools/build.js        builds dist/standalone.html
tests/                see below
report/               figures.py + make_report.py -> the PDF report (numbers read from results/*.json)
docs/audit_notes.md   notes written during development for the AI audit
```

## Tests
```
node tests/test_engine.js                              # 42 benchmark checks against published values
node tests/dump_engine.js && python3 tests/check.py    # 51 independent cross-checks (scipy / numpy)
node tests/ui_test.js ; node tests/ui_unseen.js        # 25 + 6 browser checks (needs: npm i playwright)
PAGE=../dist/standalone.html node tests/ui_test.js     # same against the single-file build
```

## Re-running the design (e.g. if the data change)
```
node tools/site.js 2 1.5 ; node tools/site.js 2 3 ; node tools/site.js 2 4
for D in 1.5 3 4 4.4 ; do node tools/raft.js 2 $D 0.9 ; done
G=2 python3 report/figures.py ; G=2 python3 report/make_report.py
```
(The first argument is the group number g. The report also reads the g = 1, 5, 12 result files for its sensitivity tables.)

## Deploy on GitHub Pages
Push this folder to a GitHub repository, then Settings -> Pages -> Deploy from a branch -> `main` / root. The site is served at `https://<account>.github.io/<repository>/`.

## Assumptions to confirm
The missing load of column C4 (assumed 1450 kN, M = 0; the instructor gave no further information), BH-3 clay parameters estimated from correlations, and sources not verified against the primary text (IS 2131:1981, IS 6403 Table 2, the IS 1904 raft row). Details: section 2 and 9 of the report.
